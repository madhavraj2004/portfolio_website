# portfolio_website

This repository contains the source code for a personal portfolio website.

## Technologies Used

- HTML (93.3%)
- CSS (5.1%)
- JavaScript (1.6%)

## Features

- Responsive design for different devices
- Showcases personal projects and skills
- Contact section for reaching out

## Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com/madhavraj2004/portfolio_website.git
   ```
2. **Navigate to the project directory:**
   ```bash
   cd portfolio_website
   ```
3. **Open `index.html` in your web browser to view the website.**

## Customization

- Update HTML, CSS, and JavaScript files to personalize the content, appearance, and interactivity.
- Add your own projects, experiences, and contact information as needed.
